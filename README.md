# Binance Futures Trading Bot

## Overview
A Python command-line trading bot for Binance Futures Testnet.

## Features
- Place Market Orders
- Place Limit Orders
- Input Validation
- Logging
- Environment Variables (.env)
- Binance Testnet API
- Professional Project Structure

## Technologies
- Python
- python-binance
- python-dotenv

## Installation

pip install -r requirements.txt

## Run

python cli.py

## Example

Symbol: BTCUSDT
Side: BUY
Type: MARKET
Quantity: 0.001
